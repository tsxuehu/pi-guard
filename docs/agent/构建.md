# 构建 agent

详细的环境搭建步骤见 [开发环境搭建](../开发环境搭建.md)。

## 构建

```bash
cmake -B build/agent -S project/agent
 cmake --build build/agent -j"$(nproc)"
```

产出：`build/agent/pi-guard-agent`（主程序）及 `cli/` 下各工具。

`compile_commands.json` 生成在 `build/agent/`，项目根目录 `.clangd` 已配置指向该目录。

## CMake 选项

| 选项 | 默认 | 说明 |
|------|------|------|
| `CMAKE_BUILD_TYPE` | — | `Release` / `Debug` |
| `BUILD_TESTING` | OFF | ON 时加入测试 |
| `PI_GUARD_LOG_BACKEND` | spdlog | 仅支持 `spdlog` |

## 安装

```bash
cmake --install build/agent --prefix /usr/local
```

## CMake 拓扑

`add_subdirectory` 顺序：**foundation → 各功能模块 → runtime → cli**，最终定义 `pi-guard-agent`（链接 `pi_guard_runtime`）。

模块与目标名一览见 [工程结构](工程结构.md)。
