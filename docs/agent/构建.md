# project/agent 构建说明

树莓派侧 C++ 代理 `pi-guard-agent`，位于 `project/agent`，CMake + C++17 组织。

## 环境要求

| 项   | 要求                          |
| ---- | --------------------------- |
| CMake | ≥ 3.16                     |
| 编译器  | 支持 C++17 的 g++ / clang++ |

## 外部依赖

| 依赖                              | 用途                       |
| --------------------------------- | ------------------------ |
| **spdlog**                        | infra/log 日志模块（默认后端）    |
| **OpenCV**（core / highgui / imgproc） | cli/preview-video 工具     |
| **ALSA**（libasound2-dev）         | capture/audio 音频采集模块   |

Ubuntu 一键安装：

```bash
sudo apt install build-essential cmake pkg-config libspdlog-dev libopencv-dev libasound2-dev
```

## 构建

仓库根目录 out-of-source 构建（目录 `build/agent`）：

```bash
cmake -B build/agent -S project/agent
cmake --build build/agent -j"$(nproc)"
```

产出：

- `build/agent/pi-guard-agent` — 主可执行文件
- `build/agent/cli/preview-video/preview-video` — 可选预览工具

配置阶段在 `build/agent` 生成 `compile_commands.json`，便于 clangd / IDE 解析头文件路径（项目根目录已配置 `.clangd` 指向该文件）。

### 安装

```bash
cmake --install build/agent --prefix /usr/local
```

可执行文件安装到 `<prefix>/bin/`。

## CMake 选项

| 选项                      | 说明                                         |
| ----------------------- | ------------------------------------------ |
| `PI_GUARD_LOG_BACKEND`  | 日志后端，仅支持 `spdlog`（默认），其他值配置阶段报错 |
| `BUILD_TESTING`         | ON 时加入 `tests/` 子目录，生成 CTest 可执行文件   |
| `CMAKE_BUILD_TYPE`      | `Release` / `Debug`，按需指定              |

示例（Release + 关闭测试）：

```bash
cmake -B build/agent -S project/agent -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=OFF
cmake --build build/agent -j"$(nproc)"
```

## CMake 拓扑

`add_subdirectory` 顺序：**foundation → 各功能模块 → runtime → cli**，最终定义 `pi-guard-agent`（链接 `pi_guard_runtime`）。

模块与目标名一览见 `docs/agent/工程结构.md`。构建目录（`build/agent`）勿提交版本库。
